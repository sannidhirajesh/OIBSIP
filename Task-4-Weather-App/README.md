# OASIS Advanced Weather App

Python Tkinter weather application for OASIS Internship Task 4.

Features:
- Current weather
- Temperature °C/°F
- Humidity and wind
- Weather icon
- Next 6 hours
- Next 5 days
- Celsius/Fahrenheit switch
- GUI error messages
- Invalid city/API key/network/timeout handling

## Run
1. Install Python 3.10+.
2. Run `python -m pip install -r requirements.txt`.
3. Run `python app.py`.
4. Enter your OpenWeatherMap API key and click Save Key.
5. Enter a city and click Get Weather.

The API key is stored locally in `weather_config.json` and should not be committed to Git.
